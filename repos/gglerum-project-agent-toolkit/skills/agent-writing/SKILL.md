# Agent writing

State what each pointer is for and the conditions that should lead an agent to it. Front-load the discriminating trigger; do not make every keyword a universal activation rule. Put shared essential steps in the entrypoint and mode-specific detail behind clear links.

Separate ordered actions from reference material. Give consequential steps observable completion criteria, preserve consumer authority, and keep one source of truth per meaning. Document unwritten conventions and material reasons rather than copying discoverable configuration or --help.

Read scripts/templates and sibling dependencies before editing their instructions. Remove stale, contradictory or redundant guidance. Verify local links and documented invocations. Keep the authoring/adoption record outside the instruction body when it does not change agent behavior.
