# Ux validation

Read existing findings and decisions before building. State the scenario and acceptance questions in words a participant understands. Use a small lab only for the unresolved interaction; preserve shared controls with explicit markers rather than cloning an older prototype.

Automated checks establish consistency and behavior under test; they are not human acceptance. Facilitate the real participant, record hesitation/confusion/recovery as observations, and ask for the actual human decision when the project requires one.

Use [UX workspace tools](../../tools/ux-workspace/README.md) for manifest/marker consistency and [reference lookup](../../tools/reference-library/README.md) when a local design library is authorized. Keep prototype content and product decisions outside reusable scaffolding.
