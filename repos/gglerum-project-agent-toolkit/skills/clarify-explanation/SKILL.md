# Clarify explanation

Identify the unexplained concept, replace it with familiar words and use one concrete before/after example. Keep technical names only when the user needs them to act.

State what is already decided, the actual choice still open and the consequence of each option. Preserve material limitations and existing authorization. Check understanding through the user's next decision rather than repeating the original jargon at greater length.
