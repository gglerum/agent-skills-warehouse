# Codex notes

Read with the [runtime](runtime-contract.md), [evidence](evidence-contract.md) and
[report](report-contract.md) contracts. Pass the actual surface and version;
unsupported ones stay gaps. Host-injected skills, tools and managed context are not
local CLI files.

Adapter status: **validated on 1 rollout**, metadata shapes only (2026-11-12).
All 32 calls had matching results, but their text/list payloads give no structured
outcome. Ten native `FileChange` items have no call IDs for attribution. These
remain coverage gaps; this is not live behavior or startup/discovery validation.

Before proposing savings, keep these apart:
- Inherited AGENTS.md scope and precedence must be preserved.
- Skill metadata advertisement, body loading and invocation are different facts.
- Check whether tools are deferred in the actual runtime before claiming deferral
  savings.
- Installed MCP entries do not prove exposed schemas or context cost.
- Shell access is inference. A successful direct read shows delivery, not how much
  was read. No transcript does not prove non-use.

Cite workflows, tests and planned work as architecture evidence, and keep recovery
and release routes. Use only existing, authorized diagnostics; do not enable
tracing. Paired comparisons follow the [validation contract](validation-contract.md);
the audit commands never launch an agent.
